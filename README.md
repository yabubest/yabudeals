# yabudeals# yabudeals 

Unabhängiges Schnäppchen- & Deal-Portal.

## 📁 Projektstruktur
- `index.html` – Hauptseite mit aktuellen Top-Deals
- `amazon.html` – Spezialseite für Amazon Angebote
- `aliexpress.html` – Spezialseite für AliExpress Deals
- `blog.html` – Ratgeber & Blogartikel
- `deal-template.html` – Vorlage für neue Einzel-Deals
- `sitemap.xml` & `robots.txt` – Google SEO Einstellungen
